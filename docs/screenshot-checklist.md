# Shopify Listing Screenshot Checklist

Capture production-quality screenshots at Shopify's required dimensions and
without browser developer tools, personal information, test passwords, or
misleading sample metrics.

Required subjects:

1. Dashboard with real storefront events and simulations clearly separated.
2. Protection readiness checklist showing the theme embed connected.
3. Incident Timeline with risk, decision, reason codes, masked IP, and ASN.
4. One-click Unblock and Whitelist recovery controls.
5. Protection settings with Auto Block, Strict Mode, and threshold controls.
6. Email alert and weekly-report configuration with provider connected.
7. Shopify theme editor showing the BotShield app embed toggle.
8. Storefront challenge screen.
9. Storefront blocked page with recovery reference code.
10. Weekly report and Security Score based on real data.

Before capture:

- Configure Resend and send successful test messages.
- Use a non-expiring production database.
- Remove temporary test entries.
- Ensure support email and legal links are live.
- Do not show claims such as edge WAF, guaranteed blocking, or revenue saved.
