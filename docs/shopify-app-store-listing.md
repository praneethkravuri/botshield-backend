# BotShield Shopify App Store Listing Draft

## App name

BotShield

## Subtitle

Monitor suspicious storefront traffic and automate browser-based responses.

## Short description

BotShield records real storefront security events, scores suspicious browser
traffic, and helps merchants challenge, block, allow, and recover visitors.

## Long description

BotShield gives Shopify merchants a clear view of suspicious storefront
activity without mixing test traffic into production metrics.

With the BotShield theme app embed enabled, compatible storefront browsers send
request context to BotShield for risk scoring. Merchants can review decisions,
manage blocklists and whitelists, challenge suspicious sessions, recover from
false positives, and receive security alerts and weekly summaries.

BotShield includes:

- Real storefront event collection and incident history
- Rule-based risk scoring with ASN, VPN, proxy, and datacenter context
- Configurable Auto Block, Strict Mode, and protection thresholds
- Browser challenge and blocked-session experiences
- Blocklist, whitelist, Unblock, and one-click recovery controls
- Email incident alerts and weekly reports
- Setup readiness and security posture indicators
- Separate diagnostic simulations that never alter real enforcement

BotShield uses a Shopify theme app embed and storefront JavaScript. It is not an
edge WAF or server-side Shopify traffic interceptor. Browsers that disable or
bypass JavaScript might not be inspected.

## Feature bullets

- Inspect and record real storefront browser events
- Challenge or block suspicious sessions using configurable rules
- Understand incidents with risk scores and reason codes
- Recover false positives with Unblock and Whitelist
- Receive high-risk alerts and weekly security reports
- Keep simulations separate from production protection data
