## Short description

BotShield helps Shopify merchants detect suspicious bot traffic, block risky IP activity, and control storefront protection from a clean security dashboard.

## Full description

BotShield gives merchants a simple way to monitor suspicious traffic and take action before abusive visitors impact the storefront.

With BotShield, merchants can:

- run live traffic scans
- score traffic as low, medium, or high risk
- block suspicious IP activity
- whitelist trusted visitors
- enable strict protection mode
- review scan history and enforcement evidence
- manage protection settings from one dashboard

BotShield is designed to make storefront protection easier to understand, easier to control, and easier to trust.
